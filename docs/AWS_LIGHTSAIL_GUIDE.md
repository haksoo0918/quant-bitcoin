# ☁️ AWS Lightsail 퀀트 봇 배포 및 고정 IP 심층 가이드

본 문서는 아마존 웹 서비스(AWS) 환경에서 퀀트 자동매매 봇(`quant-bitcoin`)을 무인 구동하기 위해 전수 조사한 최신 팩트(2025~2026년 기준) 및 실행 매뉴얼입니다.

---

## 1. AWS EC2 vs Lightsail 비교 및 분석

| 구분 | **AWS EC2 (일반 가상서버)** | **AWS Lightsail (간편 가상서버)** |
| :--- | :--- | :--- |
| **무료 기간** | **계정 생성 후 12개월 (1년) 무료** | **신규 가입 시 90일 (3개월) 무료** |
| **공인 IPv4 요금** | **월 750시간 무료 포함 (12개월간 $0)** | **인스턴스 번들에 포함 (90일간 $0)** |
| **무료 기간 내 비용** | **매월 0원 ($0)** | **매월 0원 ($0)** |
| **무료 기간 종료 후** | 사용량 기반 과금 (인스턴스 + IP 시간당 과금) | **월 $5 (약 6,800원 정액제, 고정 IP 포함)** |
| **서버 위치** | 서울 리전 (`ap-northeast-2`) | 서울 리전 (`ap-northeast-2`) |
| **장점** | **무료 기간이 1년으로 가장 긺 (0원 유지 최적)** | 무료 종료 후에도 월 $5로 비용이 완전히 고정됨 |

> 📌 **정확한 결론**: 
> * **1년간 완전 무료(0원)**로 돌리려면 **AWS EC2 프리티어(`t3.micro` + 탄력적 고정 IP)**가 가장 유리합니다.
> * 1년이 지난 후에도 매달 5달러 정액제로 신경 안 쓰고 쓰려면 **Lightsail**이 유리합니다.

## 2. Lightsail 상세 스펙 및 비용 구조

* **추천 번들**: Linux/Unix $5 플랜
  * **CPU / RAM**: 1 vCPU, 1 GB RAM (파이썬 퀀트 봇 실행에 충분한 사양)
  * **스토리지**: 40 GB SSD
  * **네트워크**: 1 TB 데이터 전송량 포함
  * **공인 고정 IPv4**: 1개 기본 제공 (인스턴스 연결 시 0원)
* **비용**:
  * **최초 90일**: $0 (750시간/월 무료 제공으로 24시간 켜두어도 과금 0원)
  * **90일 경과 후**: 월 $5 (환율 1,380원 기준 약 6,900원)
  * ⚠️ *주의*: 인스턴스를 삭제하지 않고 정지만 시켜두더라도 플랜 요금이 청구되므로, 완전히 사용을 중단할 때는 [인스턴스 삭제]를 해야 합니다. 고정 IP 역시 인스턴스에 연결되어 있으면 무료이지만, 연결 해제 상태로 방치하면 시간당 $0.005가 부과되므로 인스턴스와 함께 삭제해야 합니다.

## 3. 구축 및 거래소 연동 4단계 순서도

```
[1단계: 가입 및 생성] ──> [2단계: 고정 IP 할당] ──> [3단계: 거래소 IP 등록] ──> [4단계: 봇 실행/스케줄러]
   AWS 계정 생성            Lightsail 고정 IP 생성       업비트/빗썸 관리페이지          리눅스 crontab 등록
  서울 리전 $5 인스턴스        인스턴스에 1초 연결          해당 고정 IP 입력 허용          매일 09:05 KST 자동실행
```

### 상세 절차

#### 1단계. Lightsail 인스턴스 생성
1. [AWS 콘솔](https://lightsail.aws.amazon.com/) 접속 ➔ **[인스턴스 생성]** 클릭
2. **위치**: `서울 (Zone A/C)` 선택
3. **플랫폼/청사진**: `Linux/Unix` ➔ `OS 전용` ➔ `Ubuntu 22.04 LTS` 또는 `Ubuntu 24.04 LTS`
4. **인스턴스 플랜**: **$5 USD/월** (3개월 무료 사용 가능 배지 확인)
5. **인스턴스 이름**: `quant-bot` ➔ **[인스턴스 생성]** 클릭

#### 2단계. 고정 IP 생성 및 연결 (가장 중요)
1. Lightsail 상단 탭에서 **[네트워킹(Networking)]** ➔ **[고정 IP 생성]** 클릭
2. 방금 만든 `quant-bot` 인스턴스에 연결 지정 ➔ **[생성]**
3. 화면에 표시되는 **공인 고정 IP(예: `13.124.xxx.xxx`)**를 복사

#### 3단계. 거래소(업비트/빗썸)에 고정 IP 사전 등록
1. **업비트**: [고객센터] ➔ [Open API 관리] ➔ 발급된 API Key 수정/신규 발급 ➔ 복사한 고정 IP 입력 후 인증 완료
2. **빗썸**: [고객센터] ➔ [API 관리] ➔ API Key 발급/수정 ➔ 복사한 고정 IP 입력 후 인증 완료

#### 4단계. 코드 복사 및 크론탭(스케줄러) 가동
1. Lightsail 웹 화면에서 `quant-bot` 카드의 터미널 아이콘(`>_`) 클릭 (별도 프로그램 없이 브라우저에서 SSH 터미널 열림)
2. 아래 명령어로 소스 다운로드 및 패키지 설치:
   ```bash
   sudo apt update && sudo apt install -y python3-pip git
   git clone https://github.com/haksoo0918/quant-bitcoin.git
   cd quant-bitcoin
   pip install -r requirements.txt
   nano .env # API 키 및 디스코드 웹훅 붙여넣기 후 Ctrl+O, Enter, Ctrl+X
   ```
3. 매일 아침 09:05 KST 크론 등록:
   ```bash
   crontab -e
   # 맨 아래 한 줄 추가:
   5 9 * * * cd /home/ubuntu/quant-bitcoin && python3 src/main.py --live >> /home/ubuntu/bot.log 2>&1
   ```
