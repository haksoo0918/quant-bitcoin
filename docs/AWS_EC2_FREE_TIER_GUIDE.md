# ☁️ AWS EC2 12개월 무료(0원) 고정 IP 배포 가이드

본 문서는 AWS EC2 프리티어를 활용하여 **서울 리전에서 고정 공인 IP를 할당받아 1년간 100% 무료($0)**로 퀀트 봇을 구동하는 전수 검증 매뉴얼입니다.

---

## 1. AWS EC2 프리티어 핵심 팩트 (12개월)

* **컴퓨팅**: `t2.micro` 또는 `t3.micro` 인스턴스 **월 750시간 무료** (서울 리전 지원, 24시간 풀가동 시 약 744시간으로 1대 100% 무료)
* **공인 IPv4**: **월 750시간 무료 제공** (2024년 2월 IPv4 유료화 도입 시 AWS가 12개월 프리티어 계정에 750시간 무료 크레딧을 공식 기본 탑재함)
* **고정 IP (Elastic IP)**: 인스턴스 1대에 할당하여 연결해 두면 월 750시간 범위 내에서 **과금 0원**
* **스토리지**: 범용 SSD(gp3/gp2) **30 GB 무료**
* **총 비용**: **최초 12개월간 매월 $0 (0원)**

---

## 2. 4단계 구축 매뉴얼

```
[1단계: EC2 인스턴스 생성] ──> [2단계: 탄력적 IP(고정 IP) 할당] ──> [3단계: 거래소 IP 사전 등록] ──> [4단계: 봇 실행 및 크론 등록]
    서울 리전 t3.micro            탄력적 IP 생성 후 인스턴스 연결         업비트/빗썸 Open API 등록          매일 09:05 KST 자동실행
```

### 상세 절차

#### 1단계. EC2 인스턴스 생성
1. [AWS 콘솔](https://console.aws.amazon.com/ec2/) 접속 ➔ 우측 상단 리전이 **[아시아 태평양(서울) ap-northeast-2]**인지 확인.
2. 좌측 메뉴 **[인스턴스]** ➔ **[인스턴스 시작]** 클릭.
3. 설정값:
   * **이름**: `quant-bot`
   * **OS 이미지 (AMI)**: `Ubuntu Server 24.04 LTS` (프리티어 사용 가능)
   * **인스턴스 유형**: `t3.micro` 또는 `t2.micro` (프리티어 사용 가능)
   * **키 페어**: [새 키 페어 생성] ➔ 이름 입력 후 `.pem` 다운로드 (보관)
   * **네트워크 설정**: 기본값 유지 (SSH 트래픽 허용)
   * **스토리지**: `20 GiB` (gp3)
4. 하단 **[인스턴스 시작]** 클릭.

#### 2단계. 탄력적 IP(Elastic IP, 고정 IP) 할당 및 연결
1. EC2 좌측 메뉴 **[네트워크 및 보안]** ➔ **[탄력적 IP]** 클릭.
2. 우측 상단 **[탄력적 IP 주소 할당]** ➔ 네트워크 경계 그룹(서울 확인) ➔ **[할당]** 클릭.
3. 생성된 탄력적 IP 선택 ➔ 상단 **[작업]** ➔ **[탄력적 IP 주소 연결]** 클릭.
   * **리소스 유형**: 인스턴스
   * **인스턴스**: 방금 생성한 `quant-bot` 선택
   * **[연결]** 클릭.
4. 이제 이 탄력적 IP(예: `3.36.xxx.xxx`)가 서버의 **영구 고정 IP**가 됩니다.

#### 3단계. 거래소(업비트/빗썸)에 고정 IP 등록
1. **업비트**: [고객센터] ➔ [Open API 관리] ➔ 해당 IP 입력 후 등록.
2. **빗썸**: [API 관리] ➔ 해당 IP 입력 후 등록.

#### 4단계. 서버 접속 및 봇 설치
1. EC2 인스턴스 목록에서 `quant-bot` 선택 ➔ 상단 **[연결]** ➔ **[EC2 인스턴스 연결(브라우저 기반 SSH)]** 클릭 (별도 프로그램 없이 바로 웹 터미널 오픈).
2. 명령어 입력:
   ```bash
   sudo apt update && sudo apt install -y python3-pip git
   git clone https://github.com/haksoo0918/quant-bitcoin.git
   cd quant-bitcoin
   pip install -r requirements.txt --break-system-packages
   nano .env # API 키 및 디스코드 웹훅 붙여넣기 후 Ctrl+O, Enter, Ctrl+X
   ```
3. 매일 09:05 KST 자동 실행 크론탭 등록:
   ```bash
   crontab -e
   # 맨 아래 추가:
   5 9 * * * cd /home/ubuntu/quant-bitcoin && python3 src/main.py --live >> /home/ubuntu/bot.log 2>&1
   ```
