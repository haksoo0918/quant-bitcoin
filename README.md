# 📈 암호화폐 퀀트 자동매매 & PWA 웹 대시보드 시스템

이 프로젝트는 **업비트(Upbit)**, **빗썸(Bithumb)**, 그리고 **바이낸스(Binance)** 3대 거래소 API를 연동하여, 엄밀한 퀀트 전략을 바탕으로 매일 오전 09:05(KST) 포트폴리오의 리밸런싱 방향을 분석·자동 집행하고, 체결 리포트를 디스코드로 전송하는 독립형 암호화폐 퀀트 트레이딩 시스템입니다.

또한 모바일 및 데스크톱 환경에서 당일 매매 가이드, 최근 60일 인터랙티브 지표 차트, 3대 거래소 전략 현황, 그리고 **거래 내역 및 자산 현황(일자별 총자산 추이 그래프 & 체결 장부)**을 한눈에 확인할 수 있는 독립형 **PWA 웹 대시보드**를 함께 제공합니다.

## ⚙️ 상세 전략 알고리즘 및 차이점

### 1. 업비트 메인 전략 (원화 기반 50:50 듀얼 모멘텀)
* **대상 자산**: BTC, ETH (목표 비중 각 50%)
* **실행 주기**: 매일 오전 09:05 KST
* **개별 추세 필터**:
  * **BTC (220일 SMA ±2% 버퍼)**:
    * 신규 매수 (미보유 시): `현재가 >= 220일 SMA * 1.02`
    * 매도/현금화 (보유 시): `현재가 < 220일 SMA * 0.98`
  * **ETH (50일 SMA ± 1.5 ATR 밴드)**:
    * 신규 매수 (미보유 시): `현재가 >= 50일 SMA + (ATR(14) * 1.5)`
    * 매도/현금화 (보유 시): `현재가 < 50일 SMA - (ATR(14) * 1.5)`
* **비중 밴드 리밸런싱**:
  * 보유 코인 평가액이 총자산 대비 60%(목표 50% + 10%p 허용 밴드)를 초과할 경우, 초과분을 즉시 시장가 매도하여 원화(KRW)를 회수하고 50:50 포트폴리오를 유지합니다.

### 2. 빗썸 서브 전략 (이더리움 SuperTrend + 50일 SMA 추세 추종)
* **대상 자산**: ETH (100% 집중 매수 vs 100% 현금화)
* **전략 모델**: SuperTrend(7, 3.5) 변동성 밴드와 50일 SMA 대추세 필터를 결합한 단독 고수익/저낙폭 모델
* **진입/보유 (100% 풀매수)**: `종가 >= 50일 SMA` AND `SuperTrend == Green(상승 추세)`
* **청산/현금화 (100% 현금 보존)**: `종가 < 50일 SMA` OR `SuperTrend == Red(하락 추세)` (MDD -25% 철저 통제)

### 3. 바이낸스 메인 전략 (테더 기반 50:50 동적 리밸런싱)
* **대상 자산**: BTCUSDT, ETHUSDT (목표 비중 각 50%)
* **실행 주기**: 매일 오전 09:05 KST (UTC 00:00 일봉 마감 직후)
* **글로벌 최적 지표 필터 (최근 5.2년 실데이터 검증)**:
  * **BTC**: **200일 SMA 대비 ±2.0% 버퍼** (220일 대비 글로벌 테더 시장에서 최적 추세 반응 확인)
  * **ETH**: **40일 SMA 대비 14일 ATR의 1.2배 채널**
* **동적 리밸런싱**:
  * 업비트와 동일하게 한쪽 자산이 총자산의 60%를 초과하면 초과분을 즉시 시장가 매도하여 안전하게 테더(USDT) 현금을 50% 수준으로 확보합니다.

### 3. 로컬 PC 실행 방법 (CLI 인자 및 `.env` 환경 설정)

로컬 환경에서는 API Key를 **`.env`** 파일에 안전하게 보관하고, 실행 옵션은 **CLI 명령어 인자(Arguments)** 로 직관적으로 제어합니다.

#### 1) 환경 변수 설정 (`.env`)
프로젝트 루트의 `.env` 파일에 3대 거래소 API Key 및 웹훅 주소를 입력합니다.
```env
UPBIT_ACCESS_KEY=실제_업비트_액세스키
UPBIT_SECRET_KEY=실제_업비트_시크릿키
BITHUMB_ACCESS_KEY=실제_빗썸_액세스키
BITHUMB_SECRET_KEY=실제_빗썸_시크릿키
BINANCE_ACCESS_KEY=실제_바이낸스_API_KEY
BINANCE_SECRET_KEY=실제_바이낸스_SECRET_KEY
DISCORD_WEBHOOK_URL=디스코드_웹훅_주소
```
*( `.env` 파일은 `.gitignore`에 등록되어 있어 GitHub에 업로드되지 않습니다. )*

#### 2) 목적별 CLI 실행 명령어

* **모드 A. 3대 거래소 방향성(시그널) 확인 (API 키 불필요)**:
  ```bash
  python src/main.py --signal-only
  ```
* **모드 B. 로컬 모의 매매 테스트 (Dry-Run)**:
  ```bash
  python src/main.py --dry-run
  ```
* **모드 C. 실제 3대 거래소 자동 매수/매도 주문 집행 (Live Trading)**:
  ```bash
  python src/main.py --live
  ```
* **거래소 선택 실행 옵션**:
  * 빗썸 제외 실행: `python src/main.py --live --no-alt`
  * 바이낸스 제외 실행: `python src/main.py --live --no-binance`
